# Architecture: Runtime Adapter Contract (`RuntimeHarness`)

## 1. Universal Contract

The `RuntimeHarness` abstract base class provides the interface for pluggable execution runtimes:

```python
class RuntimeHarness(ABC):
    @property
    def runtime_name(self) -> str: ...
    def start_operation(self, intent: Dict[str, Any]) -> DurableOperation: ...
    def submit_action(self, action: ActionRequest, authorization: AuthorizationDecision, operation: Optional[DurableOperation] = None) -> Dict[str, Any]: ...
    def observe_operation(self, operation_id: str) -> Dict[str, Any]: ...
    def get_execution_state(self, operation_id: str) -> OperationState: ...
    def cancel_operation(self, operation_id: str, reason: str = "") -> bool: ...
    def recover_operation(self, operation_id: str) -> Dict[str, Any]: ...
    def spawn_agent(self, agent_config: Dict[str, Any]) -> Dict[str, Any]: ...
    def inspect_session(self, session_id: str) -> Dict[str, Any]: ...
    def subscribe_events(self, callback: Callable[[RuntimeEvent], None]) -> str: ...
    def health_check(self) -> Dict[str, Any]: ...
```

## 2. Multi-Runtime Neutrality

S-Class assurance logic is 100% neutral to which runtime harness executes actions.
Whether operated by `StepCodeHarness`, `ClaudeCodeHarness`, `CodexHarness`, or `NativeHarness`:
- Authorization policies evaluate identically.
- Replay safety rules enforce identically.
- Event schemas normalize to canonical `RuntimeEvent`.
- Project truth promotes only via S-Class independent verification.
