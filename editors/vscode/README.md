# S-Class VS Code Governance Extension

Provides Model Context Protocol (MCP) and control plane integration for VS Code.

## Features
- **Hash Chain Audit**: Verifies the SHA-256 CAS event chain directly from the command palette.
- **Doctor Diagnostic**: Runs system health probes (SQLite WAL, Ed25519 keys, verifiers).
- **MCP Integration**: Registers `sclass-mcp-server` for Claude Code / GitHub Copilot / Cursor tool discovery.
